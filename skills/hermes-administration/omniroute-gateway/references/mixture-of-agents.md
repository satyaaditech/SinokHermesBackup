# Mixture of Agents (MoA) Presets in OmniRoute

Mixture of Agents (MoA) is a capability in the OmniRoute gateway that allows combining multiple LLMs (Reference Models) to generate perspectives, and then using a final LLM (Aggregator) to synthesize the best response.

## Dashboard Settings & Concepts (http://100.92.237.45:20128/dashboard)

1. **Presets**
   * Configured presets appear as selectable models under the **Mixture of Agents** provider in Hermes.
   * You can set a preset as default, delete, or create new ones using specific names.

2. **Reference Models**
   * These are the "sub-agents" or peer models called in parallel.
   * Each reference model provides their own perspective/draft answer to the user's prompt.
   * Example reference models: `custom · daily-chat` (for fast conversational drafting) and `custom · auto/best-reasoning` (for reasoning-heavy input).

3. **Aggregator Model**
   * This is the final acting model (e.g. `custom · antigravity/gemini-3.1-pro-high`).
   * The aggregator receives the user's prompt along with all drafts/perspectives generated by the Reference Models.
   * Its job is to synthesize these into a single high-quality final response and execute any necessary tools.

## Operational Guideline
* Use MoA presets when a task requires high quality that single models might struggle to achieve, leveraging diverse perspectives before final synthesis.
* Note: MoA inherently increases latency and token cost because multiple models are queried in parallel before the aggregator runs.
