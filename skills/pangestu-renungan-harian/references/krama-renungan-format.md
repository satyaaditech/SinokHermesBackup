# Panduan Format Renungan Basa Jawi Krama & Unggah-Ungguh

*Dokumen rujukan kagem nyerat Renungan Harian saha ulasan/materi khotbah mawi Basa Jawi Krama Alus.*

## 00. Aturan Nomenklatur & Konsep Spiritual (Nomenclature & Concept Rules)

1. **Pemilik Piwulang/Ajaran**: Piwulang utawi ajaran spiritual punika kagunganipun **Sang Guru Sejati (SGS)**. 
2. **Pangestu minangka Wadah**: Pangestu (Paguyuban Ngesti Tunggal) punika organisasi/paguyuban para siswa ingkang nyinaoni piwulang Sang Guru Sejati.
3. **Penyebutan ingkang Leres**: Boten pareng nyebut "piwulang Pangestu" utawi "ajaran Pangestu". Penyebutan ingkang leres lair batos inggih punika **"piwulang Sang Guru Sejati"** utawi **"ajaran Sang Guru Sejati"**. Aturan punika wajib dipun-undhani lan dipun-trapaken wonten ing komunikasi padintenan kaliyan Pak Satya, panyusunan renungan harian, ulasan khotbah, sarta sedaya berkas riset wiki.

## 0. Aturan Sapaan miturut Wektu (Greetings by Time)

Tansah priksa jam server (setara WIB-Waktu Indonesia Barat) sakderengipun ngirim pesen utawi salam pambuka dhumateng Pak Satya. Wajib ngginakaken sapaan Krama Alus ingkang leres miturut watesan wektu punika:
*   **04.00 - 10.00 WIB**: **Sugeng enjang** (pagi)
*   **10.00 - 15.00 WIB**: **Sugeng siyang** (siang - kedah dipunserat "siyang", sanes "siang")
*   **15.00 - 18.00 WIB**: **Sugeng sonten** (sore - kedah dipunserat "sonten", sanes "sore")
*   **18.00 - 04.00 WIB**: **Sugeng dalu** (malam)

Sampun ngginakaken sapaan ingkang klentu utawi migunakaken "Sugeng enjang" terus-terusan tanpa mriksa wanci sapunika.

## 1. Patokan Judul Bab & Seksi (Labeling)

Nalika nyerat versi Basa Jawi, gantos label seksi mawi istilah Jawi ingkang trep:
*   `SABDA HARI INI` -> `PETHIKAN DINTEN PUNIKA`
*   `URAIAN` -> `ANDHARAN`
*   `PRAKTIK` -> `LAMPAH SABEN DINTEN`
*   `APLIKASI` -> `PITAKENAN PANYURAOS`
*   `TESIS UTAMA` -> `WOSING ULASAN` / `WIGATING REMBAG` (Sampun ngginakaken istilah ilmiah luar kados "tesis", gantos mawi basa ingkang prasaja lan mentes).

## 2. Kosakata & Pilihan Tembung (Krama Alus vs Krama Madya/Ngoko)

Tansah wicantenan ngginakaken **Basa Jawi Krama Alus** minangka basa standar nalika ngrubung wicara kaliyan Pak Satya (mboten kenging ngginakaken Basa Indonesia minangka gawan/default sanadyan wonten seseratan/session énggal), kajawi panjenenganipun piyambak ingkang kersa nyuwun ngginakaken basa sanesipun.

Tansah gunakaken tembung **Basa Jawi Krama Alus asli** ingkang resik lan luhur. Sampun ngantos kecampur kaliyan Krama Madya utawi Ngoko.

### A. Tata Krama "Tanya / Bertanya" (Asking Questions)
Ginakaken tembung ugi unggah-unggah ingkang leres nalika pitakenan:
- **Manawi Panjenengan (Pak Satya) mundhut pirsa dhumateng Sinox**: Ginakaken tembung **"mundhut pirsa"** (Tuladha: *"Pak Satya mundhut pirsa dhumateng kula..."*).
- **Manawi Sinox nyuwun pirsa dhumateng Pak Satya**: Wajib migunakaken tembung **"nyuwun pirsa"** (Tuladha: *"Kula nyuwun pirsa, punapa wonten perangan sanes..."*).
- **Sampun ngantos kuwalik** antawisipun "nyuwun pirsa" (kagem ragam andhap/piyambak) lan "mundhut pirsa" (kagem ragam inggil/tiyang sanes ingkang kinurmatan).

### B. Kamurnian Basa Krama Alus (Purity of Javanese Krama)
Tansah waspada kaliyan kata serapan utawi tembung basa Indonesia ingkang asring kecampur (interferensi basa). Gunakaken kosakata Krama Alus ingkang murni:
- Sampun ngginakaken **"memudahan"** utawa **"memudahkan"** ➔ kedah dipun-gantos mawi **"nggampilaken"**.
- Sampun ngginakaken **"mengganti"** ➔ kedah dipun-gantos mawi **"nggantos"**.
- Sampun ngginakaken **"dalam / didalam"** ➔ kedah dipun-gantos mawi **"ing salebeting"** (mboten pareng "njero").
- Sampun ngginakaken **"mengerti"** ➔ kedah dipun-gantos mawi **"mangertos"** (kagem piyambak: *"kula mangertos"*).
- Sampun ngginakaken **"bicara/berkata"** ➔ kedah dipun-gantos mawi **"ngendika"** (kagem Pak Satya).
- Sampun ngginakaken **"memperhatikan"** ➔ kedah dipun-gantos mawi **"nggatosaken"**.

## 3. Aturan Pengiriman Telegram (Telegram Plain Text Sharing)

* **Block Code untuk Salinan Mudah**: Saat membagikan teks renungan harian langsung di chat Telegram (sebagai pesan teks ke Pak Satya), wajib meletakkan seluruh isi teks renungan (mulai dari judul hingga pranala Google Doc) di dalam blok kode (markdown triple backticks ```markdown ... ```). Hal ini sangat penting agar Pak Satya dapat menyalin (copy) seluruh teks renungan dengan sekali ketuk (tap-to-copy) di aplikasi seluler/HP.
