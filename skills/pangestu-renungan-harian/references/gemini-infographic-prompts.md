# Gemini / Imagen 3 Full Infographic Poster Prompts

When asked to generate prompts for renungan/spiritual infographic posters (e.g. for Google Gemini / Imagen 3):

## Core Requirements
1. **Never Bare Backgrounds**: Do not generate prompt descriptions that only specify landscapes/scenery. Imagen 3 excels at typography rendering. The prompt MUST instruct the model to render real text, title, cards, and structured content directly on the poster.
2. **Layout Structure (Portrait 9:16)**:
   - **Top Header**: Category (e.g. `RENUNGAN PENYISWAAN`) + Main Giant Title in elegant serif.
   - **Middle / Upper Section**: Artistic symbolic focal illustration (calm ocean, dawn light, lotus, zen stone).
   - **Card Elements (3-4 Cards)**: Discrete, well-spaced rectangular infographic cards with distinct borders, bold card titles, and concise 1-2 sentence core values.
   - **Footer Banner**: Spiritual aphorism / laku batin (e.g. `HENENG • HENING • SUMELEH`) + reference source.
3. **Typography & Styling**:
   - Specify high-contrast readable dark text (charcoal/navy/gold) on warm parchment/cream canvas (`#F4EFEB`).
   - Mention "clean corporate spiritual infographic, crisp legible typography, sharp vector layout, museum gallery print quality, 8k resolution".
