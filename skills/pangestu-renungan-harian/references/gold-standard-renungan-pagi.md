## Pethikan Struktur (Patokan)

1. **Tanggal**: `*HARI, TANGGAL BULAN TAHUN*` (kandel, aksara gedhe sedaya).
2. **Header**: `*RENUNGAN PENYISWAAN*` (tetep, boten 'Pangestu').
3. **Judul tema**: `*Tema: ...*` + 3-4 emotikon ing pungkasan (nyambung kaliyan peringatan dinten).
4. **Salam**: `_Sugeng Enjang, Salam Karahayon_` (miring).
5. **PETHIKAN DINTEN PUNIKA**: label kandel + emoji (📖) + emotikon; Sabda verbatim satunggal paragraf saking Sasangka Jati (Sebut "Sasangka Jati, <nama kitab/sabda>:"), miring.
6. **ANDHARAN**: label `💭 *ANDHARAN* :` — 3-4 paragraf Krama Alus ingkang jero, universal, membumi; ana emotikon panyudan (🕊️).
7. **LAMPAH SABEN DINTEN**: label `🧘 *LAMPAH SABEN DINTEN* :` + ukara pambuka + 3 angka, saben angka dipunpungkasi emotikon.
8. **Konfirmasi**: `✅ Saged dipunlampahi wonten pundi kemawon sarta sawayah-wayah.`
9. **RENUNGAN**: `🎯 *RENUNGAN* :` — ringkesan siji ukara ingkang mbekta.
10. **PITAKENAN PANYURAOS**: `📝 *PITAKENAN PANYURAOS* :` — 3 pitakenan angka (bisa mawi emotikon).
11. **Panutup**: `🙏 Mugi kita sedaya tansah pinaringan Tuntunan lan Pengayoman, Sih saking Sang Guru Sejati. Satuhu. 🙏`
12. **Web Container Link (Wajib)**: `Untuk kumpulan kontemplasi lainnya bisa diakses di https://kontemplasi.satyaaditech.web.id`
13. **Google Doc Link**: Link dokumen asli.
14. **Auto-upload / Sync ke GitHub**: Saben mari damel renungan harian, simpen berkas ing `/home/satyaaditech/kontemplasi/renungan/` sarta tindakaken `/home/satyaaditech/kontemplasi/sync_to_github.sh` supados otomatis kaunggah ing GitHub Pages container.
