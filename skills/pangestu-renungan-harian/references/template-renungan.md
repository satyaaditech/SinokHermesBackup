# Template Baku Renungan Harian Pangestu

Format final — output dalam **code block** (triple backtick) agar markup WhatsApp aman.

```
*HARI, TANGGAL BULAN TAHUN*

*RENUNGAN PENYISWAAN*

EMOJI *SUBJUDUL KAPITAL: Deskripsi Singkat* EMOJI

_Salam Bahagia Bp/Ibu/Sdr semuanya,_

*📖 SABDA HARI INI :*

BUKU_SUMBER : _"*isi sabda verbatim*."_

💭 *URAIAN* :
[Paragraf 1: relate ke hidup sehari-hari, pakai emoji sesuai konteks]
[Paragraf 2: penjelasan ajaran + quote miring `_"..."_` dari buku penguat]
[Paragraf 3: kisah nyata inspirasional, atau penutup naratif]

🧘 *PRAKTIK* :

EMOJI *Nama Latihan* EMOJI — lakukan selama N hari:

1. [Langkah konkret 1]
2. [Langkah konkret 2]
3. [Langkah konkret 3]

✅ [Kapan/di mana bisa dilatih]

🎯 *RENUNGAN* :
[SATU baris aforisme — bandingkan, kontradiksi, atau rumus singkat]

📝 *APLIKASI* :
1. [Pertanyaan reflektif 1]
2. [Pertanyaan reflektif 2]
3. [Pertanyaan reflektif 3]

🙏 Semoga kita semua senantiasa berlimpah dengan Tuntunan dan Perlindungan, Sih dari Sang Guru Sejati. Satuhu 🙏
```

## Aturan Spasi & Format

| No | Aturan |
|----|--------|
| 1 | Blank line antar setiap blok/header |
| 2 | Subjudul: bold + KAPITAL, diapit emoji sesuai tema |
| 3 | Label SABDA/URAIAN/PRAKTIK/RENUNGAN/APLIKASI: emoji polos + label bold, KOLON di LUAR bold |
| 4 | Sabda: italic wrapper + bold dalam `_"*teks*."_` |
| 5 | Istilah kunci di uraian: TANPA format (bukan bold/italic) |
| 6 | Semua quote di tengah uraian: WAJIB miring `_"..."_` |
| 7 | "Buku Sasangka Jati" hanya di baris sumber dan kutipan verbatim. Selebihnya: "Ajaran Sang Guru Sejati" |

## Pantangan

- ❌ JANGAN pakai kata "kamu" — ganti "Anda" atau "Kita"
- ❌ JANGAN: "Buku Sasangka Jati mengajarkan..." — bukan buku yang mengajar
- ❌ JANGAN halusinasi: semua fakta/kisah/quote harus diverifikasi dari sumber asli
- ⚠️ Subjudul: *SUBJUDUL* bukan **SUBJUDUL** (hanya satu asterisk)
