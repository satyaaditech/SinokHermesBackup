# Standar Penulisan Berjiwa (Bawa Raos) & Tolok Ukur Khotbah 90–120 Menit

## 1. Tolok Ukur Utami (The Gold Standard)
Rujukan utama kualitas materi khotbah/ulasan kajiwan ingkang dipunkersakaken Pak Satya inggih punika berkas kanonik:
**`Ulasan Serat Panembah Bab 2 - Basa Jawi Krama Alus (90 menit)`** (`ulasan_sasangka_jati_bab2_jawi_2026-08-18.md` / Dokumen Drive ID `1S1-a3yNF2QtxGa6doSR6KLPQOy-RU70qnLGho17_1MU`).

Panulisan punika nggayuh ~30.000 karakter kagem satunggal bab ingkang fokus, ngemot sentuhan kamanungsan ingkang nembus manah, boten garing, boten namung poin-poin akademis, nanging saestu nuntun rohani.

## 2. Prinsip "Gunakan Rasa Baru Pikiran" (Heart/Feeling First, Then Mind)
- **Rasa Rumiyin, Nembé Nalar**: Nalika mbikak utawi ngudhari piwulang, kawiwitan saking *rasa kamanungsan*—ngraosaken badan, napas, rasa kuwatir, kesel, utawi bingunging manah manungsa padintenan sadèrèngipun lumebet dhateng teori metafisika inggil.
- **Nge-flow & Oratoris**: Ukara kedah ngalir kados dene wejangan lisan ingkang wening, ngrangkul, lan ngresep ing manah, boten tugal-tugel kados laporan teknis utawi poin peluru.
- **Pasemon / Analogi ingkang Cetha & Mbumi**: Saben konsep dhuwur kedah dipuncanthelaken kaliyan analogi ingkang gampil dipun-tampi (kayata: Srengenge lan Kaca Pengilon kagem Kaimpasaning Gusti, Pasemon Sang Patih kagem 7 Kamar Batin, Tetanen Pasabinan Batin kagem panyucen watak).

## 3. Paugeran Basa Krama Inggil & Martabat Ketuhanan (Lexical Guardrails)
- **DILARANG KERAS ngginakaken tembung kasar/ngoko/jasmaniah kagem Gusti/Pangeran**: Tuladhanipun tembung *ngelih*, *luwe*, *turu*, *kesel* babar pisan boten pareng dipun-trapaken dhateng Gusti.
- **Ukara Baku Krama Inggil Luhur**: 
  - Kagem Kaimpasaning Pangeran: *"Gusti Ingkang Maha Asih boten mundhut dipun-sembah utawi dipun-puji dening para kawulanipun... Awit Gusti punika Dhat Ingkang Maha Sampurna, Maha Mulya, saha Maha Impas."* (nyarirani SSJ Panembah 1 Adeg 3).
  - Tembung panyebut: *Dhat Kang Maha Suci, Suksma Kawekas, Sang Guru Sejati, Utusan Langgeng*.

## 4. Pambedan: Ringkesan Nalar (Steril) vs. Wedharan Kajiwan (Berjiwa)

| Aspek | Ringkesan Nalar / Akademis (TIDAK DISUKAI) | Wedharan Berjiwa / Bawa Raos (STANDAR WAJIB) |
|---|---|---|
| **Sipat Tulisan** | Asrep (adem), kados laporan ilmiah, kathah poin tabel tanpa rasa. | Hangat, ngrangkul, nembus manah, kebak raos welas asih lan pitedah. |
| **Konteks Kamanungsan** | Langsung teori teologis utawi metafisika inggil. | Kawiwitan saking kasunyatan gesang: nalika cuwa, kesel, ajrih, pundhak kaku, napas cendhak. |
| **Pangudharane Sabda** | Namung ngutip sabda lajeng maringi simpulan umum. | Sabda dipun-udhar tembung saben tembungipun (*tegesipun*), dipun-ambus ambeganipun. |
| **Pacing / Irama** | Kesusu mbrongot nyakup sedaya bab dados ringkesan cethêk. | Sabar, runtut, mentes, mbedhah saben adeg-adeg kanthi jangkep lan wiyar. |
| **Basa** | Basa formal kaku kados terjemahan mesin. | Basa Jawi Krama Alus ingkang membat-mentul, trapsila, lan oratoris. |

## 5. Arsitektur 5 Langkah Per Topik (5-Step Soulful Anatomy)

Saben perangan utawi adeg-adeg kedah dipun-wedharaken kanthi runtut 5 trap-trapan:

1. **Sabda Sumber**: Kutipan kanonik 100% verbatim saking kitab babon (SSJ/BRSR/SKH/TKL).
2. **Tegesipun**: Pambedhah harfiah tembung saben tembung kanthi Basa Jawi Krama Alus.
3. **Andharan Kajiwan**: Pambedhah jero saking kacamata rohani ingkang nggugah manah.
4. **Pepadhang Énggal (Insight)**: Titik pepadhang utawi pambikak kasadaran énggal.
5. **Lampah Sadinten**: Penerapan nyata ing gesang padintenan (praktik konkret).*Tegesipun & Pambedhah Tembung**: Pralambang lan teges saben tembung kunci dipun-jlentrehaken kanthi cetha lan jero.
3. **Andharan Kajiwan & Sentuhan Batin**:
   - Nyambungaken sabda kaliyan pengalaman psikologis lan fisiologis manungsa.
   - Pralambang batin dipun-gambaraken kanthi cetha (tuladhanipun: *raga ingkang asring dipuntuduh dados sumbering dosa, saiki dipunajak sowan dados piranti manembah*).
4. **Pepadhang Énggal (Insight / Paradigm Shift)**:
   - Titik balik kasadaran ingkang mbikak wawasan batin (tuladhanipun: *tembung "Hu" boten nuding dhateng langit, nanging dhateng telenging sanubari*).
5. **Lampah Sadinten (Somatic & Practical Application)**:
   - Pituduh nyata ingkang mbumi: kados pundi tumandanging awak, ambegan, tumindhak ing papan padamelan, lan sesrawungan ing bebrayan.

## 4. Pola Pambuka & Panutup Oratoris

* **Pambuka Wajib**:
  - Salam karahayon lan pakurmatan dhateng para sesepuh lan kadang siswa.
  - *Hook* eksistensial: nyentuh pamburu katentreman ing tengahing gesang, lelampahan impen marcapada (BRSR Bab I), utawi dinamika raga nalika emosi.
* **Panutup Wajib**:
  - Sintesis kajiwan: mbekta wangsul 3 tembung kunci.
  - Ajakan sumeleh ing kaheningan: *Mulih marang Mula Mulanira* wonten ing pangayomaning Sang Guru Sejati.
