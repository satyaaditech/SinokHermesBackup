# Master Educator Renungan & Devotional Architecture

## Overview
Panduan perancangan materi renungan/devotional harian tingkat lanjut (Master Educator) yang menjembatani sains modern, psikologi, dan tantangan zaman dengan kearifan spiritual otentik.

## 1. Staging Workflow (Persetujuan Bertahap)
1. **Kurasi Judul Dulu**: Rumuskan tema bulanan -> 4 sub-tema mingguan -> 28 judul harian. Masukkan ke spreadsheet dengan status `Draft Rencana`.
2. **Review Pengguna**: Dapatkan persetujuan judul TERLEBIH DAHULU sebelum menyusun naskah penuh. Jangan menyusun naskah sebelum judul disepakati.
3. **Penyusunan Naskah Lengkap**: Setelah judul disetujui, susun naskah penuh sesuai format 4-pilar.
4. **Produksi Audiovisual**: Lanjutkan ke audio TTS, video, dan publikasi.

## 2. Jembatan Sains & Kebijaksanaan Klasik
- Hubungkan konsep spiritual dengan neurosains: Default Mode Network (DMN), hormon kortisol, pembajakan amigdala, aktivasi sistem saraf parasimpatetik.
- Hubungkan dengan tantangan digital: attention economy, perampokan dopamin murah, kecemasan eksistensial, burnout kerja.
- Rumuskan formula judul magnetik: *Kekinian/Sains + Solusi Kasampurnan* (Anti-Clickbait).

## 3. Spreadsheet Architecture (22 Kolom Lean)
- Kolom A-G: No, Tgl Rilis WA, Hari & Pasaran, Bulan, Tema Bulanan, Tema Mingguan, Judul Renungan.
- Kolom H-N: Rujukan Kitab, Kutipan Asli, Terjemahan, Pangilon Rasa, Laku Panyiswan, Mutiara Rasa, Pertanyaan Refleksi.
- Kolom O-R: Status Naskah, Status Audio TTS, Status Video MP4, Status Upload YT.
- Kolom S-U: Link YouTube, Link Web, Link Docs (Wajib formula `=HYPERLINK`).
- Kolom V: Status Siar WA/TG.
- Catatan: Kolom teks siar lengkap dihapus agar tabel tetap ramping.
