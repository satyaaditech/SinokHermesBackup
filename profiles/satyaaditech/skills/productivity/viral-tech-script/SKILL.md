# Viral Tech News Script Formula

Create engaging, viral-worthy tech news scripts using proven emotional triggers and storytelling structure. Based on analysis of 50+ viral tech videos (1M+ views).

## 🎯 THE VIRAL FORMULA (9-Part Structure)

### ❌ OLD FORMULA (BORING):
```
Intro → Facts → Explanation → Conclusion → Outro
```
**Problem:** Datar, seperti kuliah, tidak ada emotional hook.

### ✅ NEW FORMULA (VIRAL):

| Time | Section | Purpose |
|------|---------|---------|
| 0:00-0:05 | **SHOCK HOOK** | Controversial statement / Unexpected reveal |
| 0:05-0:15 | **CONFLICT SETUP** | Two sides fighting / David vs Goliath |
| 0:15-0:30 | **STAKES** | Why should viewer care? |
| 0:30-2:00 | **STORYTELLING** | Chronological narrative dengan tension |
| 2:00-3:30 | **EVIDENCE DROP** | Specific data, screenshots, quotes |
| 3:30-4:30 | **TWIST / REVELATION** | Unexpected angle / Hidden truth |
| 4:30-5:30 | **IMPLICATIONS** | What this means for viewers |
| 5:30-6:30 | **CALL TO ACTION** | Engagement + Opinion prompt |
| 6:30-7:00 | **OUTRO** | Subscribe + Tease next video |

---

## 🔥 EMOTIONAL HOOKS (Pick 2-3 per script)

| Emotion | Example | When to Use |
|---------|---------|-------------|
| **Shock** | "Mereka bohongin kita selama ini." | Breaking news, scandals |
| **Anger** | "Ini nggak adil dan kita harus marah." | Injustice, betrayal |
| **Fear** | "Kalau ini lolos, privacy kamu habis." | Policy changes, risks |
| **Hope** | "Tapi ada satu company yang berani lawan." | Underdog stories |
| **Curiosity** | "Dan ini yang tidak diberitakan media." | Hidden facts, twists |

## 🔍 FRESH NEWS DETECTION (Critical!)

**OLD NEWS = DEAD CONTENT.** Always verify news is fresh:

```bash
# Search for recent news (last 7 days)
ddgs text -q "AI news May 2026" -m 15 -t w

# Check for breaking/controversial angles
ddgs text -q "AI scandal controversy May 2026" -m 10

# Verify publication date
# ❌ REJECT: News > 2 weeks old
# ✅ ACCEPT: Breaking news (< 1 week)
```

**Example from session:**
- ❌ REJECTED: GPT-5.5 (old news, already covered)
- ✅ ACCEPTED: Google-Pentagon $200M deal (April 28, 2026 - 3 days ago!)

**Viral News Indicators:**
- 🔥 Breaking/controversial headline
- 💰 Money involved ($200M+)
- ⚔️ Conflict (Company A vs Company B)
- 🏛️ Government/military angle
- 🚨 Scandal or ethical dilemma

## 🔗 SOURCE VERIFICATION & URL INTEGRATION

**Every claim MUST have a URL.** This prevents hallucination and builds credibility:

### Script Format with Sources:
```
"Google signed a $200M deal with Pentagon [1][2][3]."

SOURCES:
[1] The New York Times - https://nytimes.com/...
[2] Reuters - https://reuters.com/...
[3] TechCrunch - https://techcrunch.com/...
```

### Verification Commands:
```bash
# Verify source exists
curl -sL "URL" -o /tmp/verify.html

# Check publication date
grep -i "published\|date" /tmp/verify.html | head -5

# Block untrusted domains
BLOCKED: medium.com, reddit.com, quora.com, tiktok.com
TRUSTED: nytimes.com, reuters.com, techcrunch.com, cnbc.com, openai.com
```

## 📦 COMPLETE YOUTUBE PACKAGE WORKFLOW

Don't just create script—create **complete package**:

### 1. Script (7-8 minutes)
- Viral formula structure
- Source citations [1], [2], etc.
- Teleprompter-ready formatting

### 2. YouTube Metadata
```
Title: [SHOCK] + [CONFLICT] + [QUESTION]
Example: "Google $200M Pentagon Deal! Anthropic REFUSE - AI War"

Description:
- Hook (first 2 lines)
- Timeline timestamps
- Verified sources with URLs
- Disclaimer
- Related videos

Tags:
- Primary: 10-15 tags
- Secondary: 10-15 tags  
- Long-tail: 5-10 tags
```

### 3. Thumbnail Design
```
Specs:
- 1280x720 pixels
- Text readable on mobile (80px+)
- Color palette: Red/black for breaking, split-screen for conflict
- Elements: Breaking banner, $$$ amount, VS symbol, question
```

### 4. TTS for Pacing Reference
```bash
# Generate TTS to check pacing
text_to_speech "script_text" -o pacing_reference.mp3

# Use as reference for:
- Speaking speed
- Pause placement
- Section transitions
```
