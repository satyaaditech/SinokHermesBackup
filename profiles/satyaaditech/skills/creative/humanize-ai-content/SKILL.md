# Humanizing AI Content

## Problem Signs (AI-ish Content)
- Overly structured (3 paragraphs with same pattern)
- Pulpit language: "Demikian pula...", "Oleh karena itu..."
- Too "clean" - no hesitation, doubt, or "ehm"
- Cliché analogies (pelari, update iOS)
- Zero vulnerability - writer seems perfect
- Preaching tone instead of confession

## Human Voice Formula

### 1. Open with Vulnerability
```
"jujur ya..."
"tadi pagi saya..."
"aku juga lagi struggle..."
"sebenernya..."
```

### 2. Share Specific Moment
```
"ada yang DM..."
"tadi di jalan..."
"minggu lalu ketemu..."
```

### 3. Scripture as "Aha Moment"
```
"terus keinget ayat ini..."
"ehm, ini nyelekit..."
"pas baca ini, keinget..."
```

### 4. Ask Reader Directly
```
"pernah gitu nggak sih?"
"kamu juga?"
"atau cuma aku?"
```

### 5. Inviting CTA (not commanding)
```
"mau ikut coba?"
"kalo nggak jadi juga nggak apa-apa"
"gimana menurutmu?"
```

### 6. Warm Closing
- Use emojis naturally
- Small joke
- Short, personal prayer
- Imperfect sign-off

## Before vs After

| AI-ish | Human |
|--------|-------|
| "Seorang pelari..." | "jujur ya... Sinok lagi males" |
| "Demikian pula..." | "ehm, agak sok ya kalo..." |
| "Bangkitkan kembali..." | "mau ikut coba? kalo nggak jadi juga nggak apa-apa" |
| Preaching | Confession |

## Religious/Devotional Specific

### AI Pattern ❌
- Hook → Ayat → 3 paragraphs ✍️ → CTA generic → Closing formal

### Human Pattern ✅
- Confession/struggle → Specific moment → Ayat (nyindir/nyelekit) → Direct question → Personal invitation → Warm imperfect closing

### Key Phrases (Indonesian)
```
*jujur ya...*
*ehm...*
*agak sok ya...*
*pernah gitu nggak sih?*
*duh... keras ya*
*kalo nggak jadi juga nggak apa-apa*
*Tuhan mah sabar*
```

## Checklist
- [ ] Ada elemen imperfect/vulnerability
- [ ] Ada moment spesifik (bukan generalisasi)
- [ ] Language casual dengan "..." dan emoji
- [ ] Ada direct address ke pembaca
- [ ] CTA inviting bukan memaksa
- [ ] Closing hangat dengan humor kecil
